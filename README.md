# Tyler Song Portfolio

Personal portfolio for Tyler Song, a senior software engineer based in the SF Bay Area.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

Pushing to `main` runs the GitHub Actions workflow in
`.github/workflows/deploy-pages.yml`. In the repository’s **Settings → Pages**,
choose **GitHub Actions** as the deployment source.

The deployed site is configured for:

`https://tyler-song-cs.github.io/Portfolio/`
